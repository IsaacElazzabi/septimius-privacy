Septimius – Privacy Policy

Last updated: 2026-11-04

Septimius is a free browser extension that warns you about phishing websites. It has no account, no ads, and it does not sell data. This policy explains, in plain language, what it stores, what it sends, and to whom.

What stays on your device

  • Your settings and choices, including which optional extra tools are switched on and your Safe Preview choices.
  • The sites you chose to trust (exact site names, up to 500) and sites you told the fake-alert guard to ignore.
  • Counters of how many warnings you have had per day (no addresses), kept for 90 days.
  • Your last 50 warnings: the site name, the warning level, the reason and the time.
  • Short-lived "continue anyway" permissions: a site name and an expiry time (10 minutes).
  • A copy of the threat list (site names), refreshed from the Septimius server, so checks still work when the server is asleep.
  • A random anonymous ID created on your device. It is not linked to your identity and is used only by the community reporting feature.
  • A note that the welcome page was shown.
  • The text of the pages you visit is read on your device to look for scam wording and fake alerts. It is never stored or sent anywhere.

You can erase all of this by removing the extension.

What Septimius sends automatically

  • When you open a web page, the site name (for example example.com, not the full address) is sent to the Septimius server, which says whether it is on the threat list.
  • If you switch on "Look up domain age automatically" in Options (off by default), the site name is also sent for an age lookup.
  • Not sent: the page's text, form contents, passwords, cookies, your search terms, or the path and query part of an address.

What is sent only when you use a tool

  • Domain age button: the site name goes to the Septimius server, which asks the domain registry (RDAP) or, if you chose it in Options, WhoisFreaks.
  • Report phishing: when you press Send report, the full web address of the page is sent to the Septimius server, which emails it to the developer through an email service (EmailJS). A full address can contain private details (for example a reset link), so please do not report pages like that. A person reviews every report, and the emailed report is deleted within 90 days of being reviewed.
  • Community reports: if you take part in the community feature, your report also carries the random anonymous ID, the optional note you type and, only if you choose to be credited, the display name you type. A credited name is stored by the developer and may be shown to other Septimius users in the community panel. You can report anonymously instead. To have a name removed, email septimius.support@gmail.com.

Optional extra tools (off until you switch them on)

  • Safe Preview: the link you paste (without anything after a "#") is sent to the Septimius server, which visits it for you with a plain request and sends back the steps it followed and facts about the last page, such as whether it downloads a file or asks for a password. The server does not store or log the link. It keeps short-lived request counts in memory (up to one hour) to limit abuse.
  • Safe Preview with a picture (optional, you choose): the link is also sent to urlscan.io, a free scanning service, which opens it in its own browser as a private scan and returns a picture and a short summary. urlscan.io keeps its own record under its own policy. If a fresh scan cannot be made, the server may search urlscan.io's public scans by site name only, to show an earlier picture.
  • VirusTotal check: the full address of the page goes to the Septimius server, which asks VirusTotal. A full address can contain private details, so please do not use this on such pages.
  • AbuseIPDB check: only the IP address you type in.
  • Fake-alert guard: works only on your device and sends nothing.

Nothing in this section is sent until you press the button.

Who else receives data

Only through the Septimius server, and only for the features above: domain registries (RDAP), WhoisFreaks, VirusTotal, AbuseIPDB, urlscan.io, and the email service EmailJS, which delivers reports. The Septimius server runs on a hosting service (Render), and the threat list is stored in a hosted database. Each of these has its own privacy policy.

What the server keeps

  • The threat list: site names from public feeds and confirmed reports.
  • Display names of people who chose to be credited, as described above.
  • It does not save the sites you check, or the links you preview.
  • A report is emailed to the developer and deleted within 90 days of being reviewed. The email service keeps its own sending history.
  • Like any web host, the hosting service may keep technical request logs for a short time.

What Septimius does not do

No account. No advertising. No selling or sharing your data with advertisers. No tracking you across sites. No building a history of the sites you visit. Septimius does not process payments.

Your choices

In Options you can switch off the full-page warning, notifications and automatic domain-age lookups, switch each extra tool on or off, and change the Safe Preview picture choice with the tick box under the link. The threat-list check is how the extension works, so to stop it, remove the extension.

Changes
